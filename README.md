# Netto Facile

Voglio costruire un prototipo web di un calcolatore di retribuzione netta italiana.

Il prototipo deve permettere all'utente di inserire una RAL e visualizzare una stima del netto annuale e mensile.

Il caso d'uso supportato è un dipendente privato a tempo indeterminato, residente a Roma, con 13 mensilità e senza agevolazioni o situazioni fiscali particolari.

L'interfaccia deve essere semplice, professionale e chiara.

Per il momento concentrati esclusivamente sulla struttura dell'interfaccia e non implementare ancora le formule fiscali.
